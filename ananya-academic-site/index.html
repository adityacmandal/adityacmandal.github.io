Inverse PINNs for Stenotic Blood-Flow Reconstruction

Developed a geometry-aware inverse physics-informed neural network to reconstruct two-dimensional velocity fields and estimate wall shear stress in a stenosed artery using sparse sensor measurements.

Research question
How can physical constraints help recover flow fields from limited observations?
Method
Geometry-aware inverse modeling with physics-informed neural networks.
Evaluation
Network activations, Fourier features, wall geometry, and sensitivity to measurement noise.
